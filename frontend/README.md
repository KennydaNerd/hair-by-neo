# Hair By Neo Malapane: frontend
React + Vite + React Router. See the project root README for full setup.
- `src/config.js`: business details (WhatsApp, address, hours, socials, testimonials). Empty values show as "to be supplied".
- `src/assets.js`: image manifest. Set `DEMO_IMAGES = false` once all artwork is real photography.
- `public/assets/logo/logo-original.png`: put the original, unmodified logo here.
- `scripts/make_placeholders.py`, `scripts/IMAGE_PROMPTS.md`: demo artwork and prompts for real image generation.
